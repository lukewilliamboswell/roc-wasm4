# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/lukewilliamboswell/roc-wasm4/security/advisories/new).
Include the release or commit, compiler version, reproduction and expected impact.
Please keep exploit details private while the report is investigated.

Security fixes target the current default branch and the next release. Older
releases are not maintained separately. Published assets are immutable; fixes
ship under a new version.

Release SBOMs record known components, exact artifact hashes and explicit coverage
gaps. An incomplete inventory does not establish absence of a vulnerable component.
Use the same private reporting channel for inaccurate security or provenance data.
